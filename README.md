# Kitchkraft Website

A React and Vite website for Kitchkraft Industries, featuring product browsing, project inquiries, company information, and social links.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Local development

```sh
npm install
npm run dev
```

## Checks and production build

```sh
npm run lint
npm run build
npm run preview
```

Product and kitchen-scene images are stored locally in `public/images/`. The hero video and poster are in `public/`.
